# Pool Vision Ultra v1 (Android)
Real native Android training simulator. UI includes draggable balls, aim line and approximate future trajectories, simulated shots, collisions, bank rebounds, pocket drop, and adjustable power/side spin/top-back spin.
**This APK does not yet capture the screen or recognize live game state, and is not an ESP for online matches.** Prediction is a simplified approximation, not 100% accuracy. The original Python project is separate.
Build: gradle assembleDebug (Android SDK 35, JDK 17, Gradle 8.9).
APK output: app/build/outputs/apk/debug/app-debug.apk.
